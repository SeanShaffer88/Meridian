# Competitive Research

Official product pages reviewed 2026-10-17. This is feature-oriented desk research, not hands-on testing, a license audit or a performance comparison. The links support the limited advertised directions below; versions, support and licensing can change. Do not copy competitor marketing claims into Meridian guarantees.

## Observed product directions
- **[Q-Dir](https://www.softwareok.com/?seite=Freeware/Q-Dir):** advertises four-window navigation, tabs, folder trees, favorites, portable use and listing export.
- **[Double Commander](https://doublecmd.sourceforge.io/):** describes an open-source two-panel file manager with archive-as-directory handling, text/hex viewing and full-text search.
- **[OneCommander](https://www.onecommander.com/):** advertises dual panes, persistent tabs, Miller Columns and built-in preview.
- **[XYplorer](https://www.xyplorer.com/):** emphasizes customization and built-in scripting.
- **[Tablacus Explorer](https://tablacus.github.io/explorer_en.html):** advertises tabs, add-ons and configurable menus, keys and gestures; documents portable use and configuration-location exceptions.
- **[Multi Commander](https://multicommander.com/):** advertises a tabbed dual-pane interface, background work, archive browsing and scripting.
- **[Files](https://files.community/):** advertises tabs, dual panes, column layout, tags, previews and command customization. No comparative performance conclusion is drawn here.
- **[Unreal Commander](https://x-diesel.com/):** advertises two panels, multi-rename, directory synchronization, archives, plugin support and background file operations.

## Product implications for Meridian
- Do not chase every feature at once; make navigation and file operations reliable first.
- Support configurable panes and sessions without overwhelming the default UI.
- Build search, batch rename, comparison, previews, and archives as testable modules.
- Provide transparent queues, cancellation, recovery, and operation logs before broad automation.
- Benchmark on real Windows hardware before claiming faster or lighter than competitors.
- Preserve an offline-first, no-telemetry, no-paywall product model.
