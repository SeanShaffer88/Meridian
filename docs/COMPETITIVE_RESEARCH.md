# Competitive Research

Research is feature-oriented desk research, not a hands-on benchmark. Feature sets and licensing can change; verify current upstream sources before making release claims.

## Observed product directions
- **Q-Dir**: multi-pane layouts, folder tree, tabs, favorites/workspaces, portable usage, and listing export are prominent parts of its feature set.
- **Double Commander**: open-source dual-pane model with tabs, background operations, search, directory synchronization, and archive browsing.
- **OneCommander**: modern Windows-focused interface, dual panes, Miller Columns, and previews.
- **XYplorer**: extensive customization, scripting, and automation are key differentiators.
- **Tablacus Explorer**: add-on ecosystem, customizable menus/shortcuts/gestures, and portable use.
- **Multi Commander**: power-user operations such as batch rename, scripting, checksums, viewers, and operation logs.
- **Files (modern Windows file manager)**: modern design and integration; public user reports about performance vary by hardware, workload, and version.
- **Unreal Commander**: advertised features include directory comparison, queued operations, batch rename, archives, and plugins; confirm feature/licensing details from current authoritative sources.

## Product implications for Meridian
- Do not chase every feature at once; make navigation and file operations reliable first.
- Support configurable panes and sessions without overwhelming the default UI.
- Build search, batch rename, comparison, previews, and archives as testable modules.
- Provide transparent queues, cancellation, recovery, and operation logs before broad automation.
- Benchmark on real Windows hardware before claiming faster or lighter than competitors.
- Preserve an offline-first, no-telemetry, no-paywall product model.
